# High-Level Portable Assembly(HLPA)

HLPA is a project that lets you ~~kick LLVM out~~ remove LLVM and change to simpler IR in your own project.

HLPA 是一个让你能将 LLVM 从你的项目中~~踢出~~移除并换用更为简洁的 IR 的项目。

---

**High-Level Portable Assembly(HLPA)** is an IR. Its grammar is simple than LLVM's because it takes ideas from assembly and blends them with a unique design approach.

<strong>高层级可移植汇编（HLPA）</strong>是一个中间表示，但其语法相较于 LLVM 会更为简单，因为其语法参考了汇编并融入了独特的设计思路。

本项目支持使用 AI，但必须使用[我们提供的提示词](PROMPT.md)，如果你想了解关于本仓库的详细开发要求细节，可以复制这段提示词到 AI 让其详细说明要求，或者阅览其他要求文件。
